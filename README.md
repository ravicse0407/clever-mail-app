# AI MailMate Dashboard

Build a polished hackathon MVP called AI MailMate — AI Email Assistant.

Create a responsive web dashboard with:

- Left sidebar: Inbox, High Priority, Tasks, Deadlines, Suspicious

- Email list with realistic DEMO emails

- Email detail panel

- AI-generated summary

- Priority: High / Medium / Low

- Category

- Extracted tasks and deadlines

- Spam/phishing risk indicator

- Sentiment

- Smart reply suggestions

- Buttons: Generate Reply, Copy Reply, Mark Important

- Dashboard statistics: unread emails, urgent emails, pending tasks, deadlines

- Search and priority filters

- Modern professional UI, clean cards, blue/indigo accent colors, responsive design.

IMPORTANT:

This is a hackathon DEMO. Use clearly labeled mock/demo email data. Do not require Gmail OAuth for the MVP.

Make all major buttons and interactions functional using frontend demo data.

Include a strong landing/dashboard experience that clearly communicates the AI features.
